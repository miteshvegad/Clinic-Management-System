============================================================
                    🎯 PROJECT GOAL
============================================================

Build a terminal-based Clinic Management System.

The system will manage only FOUR main things:

    👤 Patients
    👨‍⚕️ Doctors
    📅 Appointments
    💰 Billing

At the end, the program should be able to:

    Add patients
    Add doctors
    Create appointments
    Create bills
    Search data
    Show basic reports
    Save data
    Load data

That's it.

Do NOT add authentication, medical records,
advanced analytics, or complicated features
until the basic version is finished.
